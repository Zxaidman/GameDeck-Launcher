# ADR-005: GPLv3 Licensing

## Status

Accepted

## Context

Kestrel is intended to remain open source and community-oriented while allowing people to study, modify, and redistribute the software.

## Decision

Kestrel's original project code is licensed under GNU GPLv3. The full license is provided in `LICENSE`.

Third-party dependencies remain under their own licenses and must be tracked separately.

## Rationale

GPLv3 aligns with the project's community-first goals and provides clear copyleft terms for covered derivative works.

## Consequences

Positive:
- strong copyleft
- preserves software freedoms
- clear redistribution terms

Negative:
- dependency/license compatibility must be reviewed
- contributors and redistributors must follow GPLv3 obligations

The project must not claim that GPLv3 prevents all commercial use.
